Formulas and tie-breaking rules
  • TAT = CT − AT   WT = TAT − BT   RT = first start − AT
  • CPU utilization = busy time ÷ total time (from t = 0 to the last completion) × 100. Idle gaps count as unused.
  • Ties: FCFS → earlier arrival, then row order. SJF → shorter burst, then arrival, then row order. Priority → lower number first, then arrival, then row order.
  • Round Robin: FIFO queue. A process arriving exactly when a quantum expires is queued before the preempted process.

3 · Process Control Block (PCB)

The PCB is the record the OS keeps for every process (identified by its PID). It is created with the process and deleted when it terminates. Tap a field.

4 · CPU scheduling algorithms

FCFS

Runs processes in arrival order. Simple, but a long job delays all short ones behind it (convoy effect).

SJF (non-preemptive)

Picks the shortest burst among arrived processes. Gives the lowest average wait for a given set, but needs burst times in advance and can starve long jobs.

Priority (non-preemptive)

Picks the highest priority (lowest number). Can starve low-priority jobs; aging is the usual fix.

Round Robin

Each process gets at most one time quantum, then goes to the back of the queue. Fair, with good response time; the quantum size matters (too small = many context switches, too large = FCFS).
Context switch: the kernel saves the old process's state in its PCB and loads the next one. It is pure overhead.
5 · Process operations: fork(), exec(), wait(), exit()

fork()

Creates a child that duplicates the parent.
pid = fork();

exec()

Replaces the process's memory with a new program.
execlp("ls", "ls", NULL);

wait()

Parent sleeps until a child terminates. Without it, finished children become zombies.
wait(&status);

exit()

Ends the process; the OS reclaims its memory, files and buffers.
exit(0);
